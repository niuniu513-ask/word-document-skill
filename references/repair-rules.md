# 修复规则(Repair Rules)

问题 → 修法的对照表。先诊断(validate --check / 视觉检查),再对号入座;只修确认存在的问题。

总原则:**用 Word 的机制解决 Word 的问题**。空段落、空格、手打页码都是伪解法,修复 = 用真机制替换伪解法,而不是调整伪解法。

## 1. 空白页 / 大面积空白

| 原因(先确认) | 修法 |
|---|---|
| 连续空段落被顶到新页 | `repair_docx.py --fix empty-paragraphs`(默认保留每处最多 1 个空段) |
| 段尾多余分页符 | 删掉多余的 `w:br type=page` / 分节符(检查是否误删不得删:分节符承载页眉页脚切换) |
| 表格/图片刚好挤到下页,前面留白 | 微调:缩小图片 width_cm 5-10%、收紧表格行高,或允许标题带正文自然分页 |
| 尾页只有一两行 | 收紧全篇段前段后,或接受(如实报告) |

## 2. 标题孤立页尾

`repair_docx.py --fix heading-keepnext` —— 给标题段加 `keepNext + keepLines`。
**禁止**用空段落/分页符把标题"推"到下页:内容再改动就全乱了。

## 3. 图片变形

`repair_docx.py --fix image-aspect` —— 以显示宽度为准,按图片原始像素比重算高度(同时改 wp:extent 与 a:xfrm/a:ext)。
预防:插入时永远单边指定(width_cm),不手工设高。

## 4. 页码问题

| 症状 | 修法 |
|---|---|
| 页脚是手打数字 | `repair_docx.py --fix manual-pagenum`(换成 PAGE 域,保留原对齐) |
| 封面不该有页码却有 | 封面单独成节:分节 + 首节页脚不链(previous),或首页不同(different first page) |
| 正文从"第 2 页"开始计数 | 正文节 `w:pgNumType @w:start="1"` |
| "第 X 页 共 Y 页"的 Y 错 | NUMPAGES 是全文页数,统计正文用 `SECTIONPAGES`;按需换域 |

## 5. 假标题(居中加粗的普通段落)

`repair_docx.py --fix fake-headings --fake-heading-style "标题 2"`(先 dry-run 看候选清单,确认每个都真是标题再 apply)。转换后该段继承标题样式的大纲级别,目录/导航窗格才能识别。如果某"假标题"其实是封面元素,不要转。

## 6. 编号乱

- 原生编号断档/重复:通常是段落被复制时带了个别 numPr 覆盖——删段落级 numPr 覆盖,让样式级编号接管。
- 手工编号错序:纯文本修正,顺手检查后续编号连续性。
- 中英编号混用("一、"和"1."交错):是原文档的体系,除非用户要求,不统一。

## 7. 字体混乱

- 个别段落字体突兀:该段有直接格式覆盖 → 删 run 的 rFonts 覆盖,让它回落到样式;需要区别于正文时在样式层解决。
- 中文显示西文字体(或反之):三轨道问题,按 references/word-style-rules.md §1 修 rFonts 的 eastAsia/ascii。
- 数字字体不统一:同理,确认正文样式的 ascii 轨道。

## 8. 表格问题

| 症状 | 修法 |
|---|---|
| 超出版心 | 列宽按版心重分配(总宽 ≤ 页宽-左右边距);`tblW` 用 pct 或固定值二选一,别混 |
| 跨页表头丢失 | 首行设 `w:tblHeader`(repeat header row) |
| 文字溢出单元格 | 关闭该行固定行高(trHeight 的 hRule=atLeast);缩字号是最后手段 |
| 断裂难看 | 行 `cantSplit`(整行不拆)或允许拆但保表头,渲染后看效果定 |

## 9. 目录问题

- 页码全错/未更新:`render_docx.py --update-fields`。
- 目录条目缺失:对应标题没用样式或大纲级别(假标题)→ 先修 §5,再更新域。
- 更新后目录把正文顶出乱页:正常现象,重新全篇视觉检查一遍。

## 10. 修复的验证纪律

每次 repair --apply 后:重跑 `validate --check`(问题数应下降且不新增)→ 重渲染 → 看受影响页与相邻页。修复引入新问题(比如删空段导致表题紧贴上文)时,回退该项修复,换局部手法(改用段前距)。
