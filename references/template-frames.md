# 模板大框与连续分页

适用：实验报告正文置于一个大框、模板内部只有一个巨大单元格，或用户指出“原版不是表格而是大框”。

## 先区分视觉用途与存储结构

先渲染原模板，再检查 XML。`len(doc.tables) == 1` 只能说明存在表格对象，不能证明用户需要按题分行。单格表格可能只是承载连续正文的外框。

记录两组事实：

- 视觉：大框从哪里开始、是否紧接封面身份字段、内横线是否存在、宽度、线型、内边距，以及跨页效果。
- 结构：实际使用 `w:tbl`、段落 `w:pBdr`、页面 `w:pgBorders`、文本框或形状中的哪一种。

默认保留原容器直接填充。不要为方便分页擅自按题拆行；隐藏内横线仍然会改变容器和分页行为。用户明确要求取消表格结构时，可改为普通段落加外框；这是已授权的格式修正，无需反复确认。不要将所有大框模板一律转成段落边框。

## 框宽与封面字段必须实测

段落边框的外沿不等于版心边界。左右缩进、边框 `space`、线宽，以及原表格的单元格边距都会影响框宽；去掉表格后把缩进清零，会使框线向外扩。先记录原模板渲染中的左右框线坐标，再调整缩进与边框距离，不要只比较页面边距或 `tblW`。

可用 PyMuPDF `page.get_drawings()` 提取框线或细长填充矩形的中心位置，以 PDF point 为单位比较。区分框线与图表坐标轴，核对首页和所有续页；图像像素测量须换算 DPI。采用与线宽相称的容差，并记录实测值，不能只声称“看起来等宽”。例如原单元格左右内边距为 108 twips，即 5.4pt，迁移时应计入文本缩进；这只是示例，不能当所有模板的常量。

封面字段不是纯文本槽位。课程、班级、姓名、学号的标签与填充值通常分属不同 runs，空白填充位可能已有 `w:u`。填写时保留原有 run 的下划线、字体、字间距和标签位置；不要清空全部 runs，再把整行写入第一个未带下划线的 run。原模板已有的下划线空白可以保留，新增对齐优先使用制表位。渲染后分别确认四个字段的文字下方确有线段，且线长和字段位置未明显偏离原模板。

## 用户要求取消表格结构时

1. 按文档顺序提取容器中的段落，保留运行格式、图片引用、编号、域和固定文本。若有嵌套表格、合并格或锚定形状，先核对内容顺序，不可简单遍历 `row.cells` 导致重复或漏内容。
2. 将正文段落放入主文档，按原框线参数添加一致的 `w:pBdr`。相邻段落的边框与缩进一致时，Word 可连接为一个外框；不要添加 `between` 内横线。
3. 封面字段留在框外，框内各段的左右边界保持一致。不要把页面边框直接当正文框：页面边框会包住封面及整页空白，效果不同。
4. 以实际 Word 渲染确认连续和跨页效果，不以“XML 已写入”作为验收。仅当用户明确要求无表格且原内容没有真正数据表时，才以表格数为零验收。

## 分页按小组设置，不把整题串成不可拆块

`keep_with_next` 会传递：实验名称 → 内容列表 → 说明 → 章节标题 → 代码图 → 输出图 → 分析若全设为真，会把首页正文推到第二页，或产生大片空白。

- 标题随紧接的正文；截图标签随其图片。
- 一组说明结束、导入截图结束、分析段结束时允许分页，避免跨组长链。
- 长代码与输出可以在完整行之间分页；代码图结束后可断开，与下一页的“输出标签 + 输出图”分组。
- `keep_together` 只控制单段，不能替代对整组实际高度的判断；单组超过可用页高时必须允许分拆。
- 清理继承的行单位段距 `beforeLines/afterLines` 及自动段距，再核对实际行距；只改 pt 值可能不起效。
- 继承的文档网格可能使单倍行距的代码清单仍有大行距。检查 `snapToGrid` 和实际渲染；只对需要紧凑排版的段落局部调整，不全局关闭模板网格。
- “输出截图 + 分析”也不应始终绑定为不可拆块。若下一张完整图片可放入当前页，只因后续分析被一同保留而换页，可允许分析跨页；标签仍必须随图。
- 不用连续空回车填高边框，也不要强制每题另起一页。保留题目完整性与合理利用版面需同时考虑。

留白验收不能只看总页数减少：逐页检查正文结束位置与可用页底，判断余下空间能否容纳下一个合理内容块。图表完整性、字号可读性和标题归属优先；不能为了压页数把截图缩到不可读。最后一页自然短于整页可以接受，但前面持续大面积空白仍需排查。

## 修正后验收

与原模板并排看首页及跨页边界，确认框线位置、内横线、字体、边距；检查全部页面是否出现孤立标签、截图裁断、大片非预期空白。长文可先看联系表，再放大疑似问题页。

重新对账：模板固定文本完整、每项分析在最终 PDF 中存在、截图与题号匹配、原始代码未被改写。结构体检零问题、格式差异小，都不能代替视觉验收。差异报告需如实列出容器替换、截图插入、段距和页脚等变化，不能声称格式零变化。
