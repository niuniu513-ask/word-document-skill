# 工作流:分析(Analyze)

触发:用户问"这份 Word 是什么结构/用的什么格式/帮我看看这个模板"。

## 步骤

1. `analyze_docx.py <input> -o spec.json`;必要时加跑 `inspect_styles.py`、`extract_content.py --markdown`。
2. 按 references/document-analysis.md 的"怎么读"提取要点。
3. 产出一份结构化解读,固定顺序:
   - 一句话定位(什么类型的文档、几页/几节)
   - 页面设置(纸张、方向、边距、页眉页脚、页码)
   - 样式体系(正文样式与三轨道字体;标题层级与编号体系;表格/题注样式)
   - 结构骨架(大纲树;封面占位符;目录;表格与图片清单)
   - 问题清单(spec issues + validate --check)
4. 用户只问分析时,到此为止,**不要顺手改文档**。

## 产出格式示例

> 这是一份单节 A4 纵向课程实验报告模板:
> - 页面:21.0×29.7cm,边距上下 2.54 / 左右 3.17cm;页脚居中 PAGE 域页码
> - 正文:Normal,宋体 + Times New Roman,小四,1.5 倍行距,首行缩进 2 字符
> - 标题:标题 1(黑体三号加粗)、标题 2(黑体四号),手工编号"一、/1."
> - 结构:封面(7 个填空字段)→ 五个章节标题 → 1 个仪器表格(TableGrid,4×4,表头行)
> - 问题:封面字段全部未填;图片 1 张比例正常;无目录、无修订批注
